The problem

Requests for records are tracked in email and memory. So are the responses to the firm's own requests. Follow-ups slip.

What SI does

SI keeps a tracker of each request. It records what was asked, from whom, the date sent, and when a follow-up is due. It drafts routine follow-up notes from approved wording. It shows what is overdue.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • Solo family-law practice

    The tracker lists each request with the date sent and the follow-up date. A routine follow-up is drafted from the firm's wording.

  • Small commercial-litigation firm

    Overdue requests are listed for staff. A person reviews anything that comes back before it is placed in the matter folder.

  • Two-attorney estate-planning firm

    A request is logged with who it was sent to. The follow-up draft stays inside the approved wording.

What it takes to set up

GemmiSI sets this up on your own equipment and accounts; your data stays with you. Before the firm connects anything that holds client information, it reviews the vendor's terms. It checks data retention and training practices. It confirms access controls. It gets any required client consent. Start with sample or de-identified material. Use the tracker the firm already keeps, or a simple sheet. Use the follow-up wording the firm has approved. Records stay in the firm's secured systems. Setup is often a few days.

Copy-ready prompt 
Update this records-request tracker [paste] with these new items [paste: what, from whom, date sent, follow-up due]. List what is overdue. Use only the sample or de-identified information I provide; do not include client-confidential details.
