The problem

Guests ask the same menu, allergy, and delivery questions all day. Staff answer late, or they guess when the list is not in front of them.

What SI does

SI reads only the menu, hours, allergy list, and delivery area the restaurant approved. It drafts a short reply from those pages. If the answer is not on them, the question goes to staff with no guess. A person approves anything sent. SI does not give medical advice. It does not change the menu or take an order on its own.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • Lunch counter

    A guest asks if a soup has nuts. The allergy list says it does. SI drafts that fact. A manager sends it.

  • Sushi bar

    A guest asks about a special that is not on the menu. SI does not guess. The note goes to the chef.

  • Pizza shop with delivery

    A guest asks if a street is in the delivery area. SI drafts a yes or no from the map list. Staff send it.

What it takes to set up

GemmiSI sets this up on your own equipment and accounts; your data stays with you. Save the current menu, hours, allergy list, and delivery area in one folder the shop controls. Permission is to draft, not to send. We sit with you, plan the steps, and teach you to run it. Setup is often a few days while staff check the first replies.
