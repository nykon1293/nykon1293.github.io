The problem

New inquiries land in a form, an inbox, or a text thread. The first reply sits while the day gets busy. The details never make it into one list. The person moves on.

What SI does

SI reads the new inquiry. It pulls out the name, the ask, and the contact. It drafts a first reply in your wording. It adds a row to your list or CRM. A rental inquiry, a contractor lead, and a school enrollment note all use the same steps. A person sends the reply. This is not legal advice. SI does not lease, collect rent, screen or rank applicants.

Related in this library: Rental inquiry follow-up for landlords.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • Home-service contractor

    A web form asks for a water-heater visit. SI drafts a same-day reply with two time windows. The owner sends it.

  • Property manager

    A rental inquiry names a unit and a move date. SI drafts a reply and a list row. The manager sends it. This is not a screening decision.

  • School admissions

    A family asks about a tour. SI drafts a reply from the school's approved wording. Admissions sends it.

  • Local shop

    An email asks if you are open Saturday. SI drafts a short reply and logs the lead.

What it takes to set up

Connect the form, inbox, or text tool you already use. Add a few replies you like. Name the fields your list needs. Setup is often a few days.

Try it yourself

Copy-ready prompt 
For each new inquiry in [inbox or form], draft a first reply in this tone [paste samples]. Pull out name, ask, and contact into a row for [list or CRM]. Do not promise a price, a seat, or a lease. Pause and show me before sending, submitting, posting or changing anything.
