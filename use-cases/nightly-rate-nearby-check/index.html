The problem

Nearby nightly prices move. The host finds out late, often from a guest. Checking each listing by hand does not fit the week.

What SI does

SI reads the nightly prices on the public listings the host listed, and the host's own price for the same dates. It drafts a short note on what changed. The host approves before any price is changed. SI does not change the listing, message a guest, or set a price on its own.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • One beach condo

    Three nearby listings dropped their rate for a holiday week. SI drafts the gap. The host decides whether to change the price.

  • Two-home host

    One listing page will not open. SI flags that row and still drafts the rest. The host checks the closed page.

  • Small cabin rental

    The host's price is already in line with the list. SI says no change is suggested. The host leaves the rate as it is.

What it takes to set up

GemmiSI sets this up on your own equipment and accounts; your data stays with you. Save the list of nearby listings and the dates to watch. Permission is to read public pages and draft a note, not to edit the listing. We sit with you, plan the steps, and teach you to run it. Setup is often a few days while you check the first note.
