The problem

Supplier prices change, and the estimate sheet stays on last month's numbers. Quotes go out with a cost the shop no longer pays.

What SI does

SI reads the supplier price file and the estimate sheet. It drafts the new unit price next to the old one for items that match. It flags items it cannot match. The owner approves before the new prices are used on a quote. SI does not send a quote or set a sell price on its own.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • Plumbing contractor

    A supplier file shows a higher unit cost on copper fittings. SI drafts the new cost on the sheet. The owner accepts it before the next quote.

  • Electrical contractor

    One item code does not match the sheet. SI flags it and leaves the old price. The owner matches it.

  • Roofing supplier buyer

    SI drafts the night's changes in a short list. The owner uses them on the next estimate after a review.

What it takes to set up

GemmiSI sets this up on your own equipment and accounts; your data stays with you. Before connecting anything that holds customer information, the business checks the tool's terms. It also checks data practices. It sets access controls. It limits SI to the minimum necessary. Start with sample or made-up information. Use the supplier price file and the estimate sheet the owner already keeps. Permission is to draft price rows, not to send a quote. We sit with you, plan the steps, and teach you to run it. Setup is often a few days.
