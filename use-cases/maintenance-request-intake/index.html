The problem

Requests arrive by text, email, and call in no standard form. Urgent problems get buried.

What SI does

SI turns each request into a standard ticket. The ticket has unit, issue, when it started, access notes, and photos. SI sorts tickets into queues for the manager. The queues are urgent-flag, routine, vendor needed, and awaiting tenant. Anything mentioning gas, fire, flooding, no power, or safety is flagged to the top for a person. The received note tells the tenant the request was received. It also says that in an emergency they should call 911 or the number the manager provides. SI prepares drafts for the licensed agent or owner. SI does not lease, collect rent, screen or rank applicants.

Examples

The same job looks different in different businesses. These are examples, not client results.

  • Landlord with a few rental units

    A message about [Unit] becomes a ticket with when it started and any photos. Mentions of flooding are flagged to the top for the owner.

  • Small property-management company

    Requests are sorted into urgent-flag, routine, vendor needed, and awaiting tenant. The received note uses only the manager's approved text.

  • Small brokerage

    A property the firm manages has incoming repair notes turned into tickets. The manager decides who is called.

What it takes to set up

GemmiSI sets this up on your own equipment and accounts; your data stays with you. Before connecting anything that holds applicant or tenant information, the business checks the tool's terms. It also checks data practices. It sets access controls. It limits SI to the minimum necessary. Start with sample or made-up information. Connect the inboxes the manager chooses. Give permission to read and draft, not to send. Save the received note the manager has already approved, including the emergency line. Setup is often a few days.

What a human still checks

  • The agent, broker, or manager approves before anything goes to a client, tenant, applicant, or vendor.
  • SI never sends, posts, signs, or changes records on its own.
  • Unusual items go to a "needs manager or attorney review" queue.
  • The business decides what personal data SI may see. Testing starts with sample information.
  • The manager reads the urgent queue first. The manager decides priority and which vendor is called. The manager sends all repair commitments.
  • Urgent matters are handled by a person.
