What this software is

Hermes is an AI agent on your computer, not another chat tab.

ChatGPT and Claude are chat boxes. You paste something in, they answer, then they forget. Hermes is the software around them. It lives on a Mac you control, uses the model you already pay for, and can work with your files and tools — inside limits we write down first.

The model is the brain

We hook up ChatGPT, Claude, or another model you choose, including a local one. Hermes is not the chat product. It is the software that uses that model to do work.

It stays on a machine you own

Hermes runs on your computer with your files. We agree which folders, accounts, and tools it may touch. It does not get the whole machine.

I install it and hand it off

I do the setup, the first real task, and a short walkthrough. You leave able to run it. The setups are Starter, Operator, and Connected Desk. See Desk prices →
